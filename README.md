# 年会抽奖大转盘

iOS 风格的 Next.js 年会抽奖工具，支持自定义奖项、中奖概率与奖品数量。

## 功能

- 大转盘抽奖，指针指向中奖扇区
- 自定义奖项名称、概率、数量、颜色
- 数量为 0 的奖项不可抽中，概率自动归入「谢谢参与」
- 中奖满屏烟花庆祝，「谢谢参与」无庆祝
- 设置自动保存到 localStorage

## 启动

```bash
cd lottery-wheel
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)

## 使用说明

1. 点击右上角「设置」配置奖项
2. 设置每个奖项的中奖概率（%）和剩余数量
3. 概率合计不超过 100%，剩余部分为「谢谢参与」
4. 点击「开始抽奖」旋转转盘
